# 1xcoder.dev

My personal website and portfolio. Built with Next.js, Tailwind CSS v4, and MDX.

## Overview

- `app/blog/*` - Blog posts rendered using MDX
- `app/inspiration` - Design inspiration page
- `app/sponsor` - Sponsor page
- `components/*` - Reusable UI components

## Getting Started

```bash
git clone https://github.com/1xcoder-1/portfolio.git
cd portfolio
npm install
npm run dev
```

The dev server runs on [http://localhost:3000](http://localhost:3000) using Turbopack.

## Built With

- [Next.js 16](https://nextjs.org) (App Router)
- [Turbopack](https://turbo.build/pack)
- [Tailwind CSS v4](https://tailwindcss.com)
- [MDX](https://mdxjs.com) via next-mdx-remote
- [Motion](https://motion.dev) (Framer Motion)
- [Vercel](https://vercel.com)
